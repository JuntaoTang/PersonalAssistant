# 资料驱动的报名准备

本流程组合个人 Markdown 资料、网页读取、字段匹配、飞书确认和本地记录，输出经确认的填写结果及可重看的资料来源。用户自行提交；不把截图或归档当作报名成功。

## 手机操作

1. `查资料 关键词`：检索最新个人资料，返回原文位置、来源及适用范围。
2. 直接发送公开表单链接：读取网页，展示拟填值、对应资料字段及原文位置、缺项和确认码。模型仅选择资料键，程序读取事实值。
3. 缺资料时发送 `资料 字段=值` 保存自己确认的信息；再发 `重新准备 任务编号`。新任务读取最新网页和资料，旧的待确认任务失效。
4. `填表预览 任务编号` 重看预览；资料已变化时提示失效，不给出可执行的旧确认指令。
5. 核对后发送 `确认填表 任务编号 确认码`；只填写对应版本，未知项留空，阻断填写触发的网络请求。
6. `填表结果 任务编号` 重看填写记录。记录保存在本机 `data/records/forms/`，保留当时使用的事实、来源、缺项和“未提交”状态；重启后仍可查，但后台页面不会随记录恢复。

## 约束与验收

- 只有绑定用户能读取资料、预览和结果；网页、模型或其他用户不能改写个人资料。
- 字段来源定位绑定准备时的资料哈希和行号。直接编辑 Markdown 后，下次检索与新预览读取新内容；历史位置仅对应当时版本。
- 有适用范围／有效期的事实继续保守留空，不将未来学校当作当前学校。缺项由用户自行补充，不猜测、不从网页回写资料。
- 模型进行字段匹配只需可用资料键名，不发送事实值、来源或整份资料。输入网页的值仅来自本地核验后的资料。
- 结果记录是个人数据库中的历史记录，不是新的身份事实，不参与自动填表取值。
- 用虚构资料、模拟飞书和真实本地浏览器，验证完整流程、来源、未知留空、修正后旧确认失效、新实例和另一张表复用修正、重复事件不重填、自动保存／提交请求阻断和归档重看。真实目标表单的兼容性与手机显示单独验收。
